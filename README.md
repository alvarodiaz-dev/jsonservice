# JsonService

A microservice that retrieves sample JSON data from the JSONPlaceholder API for testing and demonstration purposes. Built with ASP.NET Core 8.0.

## Quick Start

```bash
git clone https://github.com/alvarodiaz-dev/jsonservice
cd jsonservice
dotnet restore
dotnet build
dotnet run --project src/JsonServiceService.Api/JsonServiceService.Api.csproj
```

Browse to `http://localhost:5000/swagger` to access the API documentation.

For complete documentation, see the full README in the repository.
